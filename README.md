# ONU 批量 Telnet 工具

基于 PyQt5 的图形化运维工具，通过 OLT 批量登录并操作多个 ONU 设备。
支持 Telnet / SSH 两种连接方式，可发送特殊按键、控制命令间隔、设置定时任务并自动保存日志。

## 功能特性

- 图形界面：基于 PyQt5，深色主题，操作直观
- 双连接模式：支持 Telnet 和 SSH 连接 OLT
- 批量处理：一次对多个 ONU 执行相同命令序列
- 特殊命令：支持 Ctrl 组合键、方向键、Tab、Enter、Esc、Backspace，以及自定义等待
- 可调间隔：控制命令之间的等待时间，适应不同设备响应速度
- 定时任务：预设时间点自动执行，支持多个时间
- 日志功能：界面实时显示，同时写入日志文件
- 任务中断：随时停止正在执行的任务

## 环境要求

- Python 3.7 及以上（建议 3.12 及以下）
- 依赖库：PyQt5、paramiko

> 标准库 telnetlib 在 Python 3.13 中已被移除，若使用 3.13+ 需额外处理。

## 安装

    pip install PyQt5 paramiko

## 使用方法

### 1. 启动程序

    python main.py

### 2. 配置 OLT 连接

| 字段 | 说明 |
|---|---|
| OLT 连接方式 | 选择 Telnet 或 SSH |
| OLT IP | OLT 设备的管理 IP |
| OLT 账号 | 登录用户名 |
| OLT 密码 | 登录密码 |
| SSH端口 | 仅 SSH 模式显示，默认 22 |

### 3. 配置 ONU 参数

| 字段 | 说明 |
|---|---|
| ONU Telnet端口号 | ONU 的 Telnet 端口，默认 23 |
| 发送间隔（秒） | 每条命令之间的等待时间，默认 0.5 |

### 4. 输入 ONU IP 列表

在中间文本框输入，每行一个 IP：

    192.168.1.101
    192.168.1.102
    192.168.1.103

### 5. 输入命令

在右侧命令框输入，每行一条命令：

    enable
    configure terminal
    show version
    cmd(wait2)
    cmd(ctrl+c)

### 6. 启动任务

点击「启动」按钮，选择日志保存位置，程序开始执行。

## 特殊命令说明

在命令框中以 cmd(...) 格式书写。

### 等待

| 命令 | 说明 |
|---|---|
| cmd(wait3) | 等待 3 秒 |
| cmd(wait0.5) | 等待 0.5 秒 |

### Ctrl 组合键

支持 ctrl+a 到 ctrl+z：

    cmd(ctrl+c)
    cmd(ctrl+d)
    cmd(ctrl+k)

### 功能键

| 命令 | 按键 |
|---|---|
| cmd(tab) | Tab |
| cmd(enter) | Enter |
| cmd(backspace) | 退格 |
| cmd(esc) | Esc |

### 方向键

| 命令 | 按键 |
|---|---|
| cmd(up) | 上 |
| cmd(down) | 下 |

| cmd(right) | 右 |

点击界面上的「命令帮助」按钮可查看完整列表。

## 定时任务

1. 在「定时执行时间」输入框填写时间，每行一个：

       2026-06-12 23:00:00
       2026-06-13 01:00:00

2. 点击「启用定时」，选择日志保存目录。
3. 程序会在到点时自动执行任务。
4. 点击「清除定时」可清空所有待执行任务。

说明：

- 时间格式必须为 YYYY-MM-DD HH:MM:SS
- 已过期的时间会被忽略并提示
- 如果定时触发时已有任务在运行，本次定时会被跳过并记录日志

## 日志

- 界面实时日志：最多保留 100 行，超出自动清理旧行
- 日志文件：
  - 手动启动：弹窗选择保存路径
  - 定时任务：自动保存到指定目录，文件名格式 ONU_Log_YYYY-MM-DD_HH-MM-SS.txt

## 工作原理

1. 通过 Telnet 或 SSH 登录 OLT。
2. 对每个 ONU IP，发送 telnet <ONU_IP> <端口> 从 OLT 跳转到 ONU。
3. 依次发送用户配置的命令序列。
4. 读取并记录每一步的返回内容。
5. 处理完所有 ONU 后断开连接。

## 注意事项

1. Python 版本：telnetlib 在 Python 3.13 中已被移除，推荐使用 3.12 及以下。若必须用 3.13+，需自行替换 Telnet 实现。
2. 网络环境：运行本工具的机器需能访问 OLT 管理地址，OLT 需能访问各 ONU 的 Telnet 端口。
3. 凭据安全：密码仅保存在内存中，不写入日志，但日志会记录命令和返回内容，注意敏感信息。
4. 命令兼容性：不同厂商 OLT/ONU 的跳转命令可能不同，若不适用需修改跳转逻辑。
5. 编码问题：默认按 utf-8 解码，若设备使用 GBK 等编码，中文可能乱码，可修改 decode 参数。

## 常见问题

Q：连接 OLT 超时怎么办？
A：检查网络连通性、IP 和端口是否正确，确认 OLT 已开启 Telnet/SSH 服务。

Q：命令发出后没反应？
A：增大「发送间隔」值，部分设备响应较慢。

Q：返回内容是乱码？
A：设备可能使用非 UTF-8 编码，修改代码中的 decode 参数（如改为 gbk）。

Q：定时任务没执行？
A：检查时间格式是否正确、是否已过期、程序是否在运行。

Q：能同时对多个 ONU 并发执行吗？
A：当前版本为串行处理，逐个 ONU 执行。并发版本需自行改造。
